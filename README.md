# 太阳能小车机构与传动设计

本科工程训练项目。主要负责小车方案设计、结构建模、凸轮转向与传动参数匹配，公开保留能展示设计过程的模型与计算表。

## 已完成的工作

- 整理整车布置、车头/车尾/车身的迭代模型。
- 建立凸轮、凸轮轴、底板、电机固定座及主动轮等结构模型。
- 将路径长度、轮径、齿轮传动比、读卡时间约束与电机转速关联，使用表格公式进行参数匹配。
